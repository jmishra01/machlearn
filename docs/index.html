Classical machine learning,
built to be dependable in Rust.

MachLearn is a CPU-first machine-learning library for dense tabular data — deterministic estimators, validated datasets, structured errors, and no silent NaN propagation. Backed by ndarray and an internal faer solver, with optional Python bindings.

Worked examples

Real datasets, not toy synthetic data

Both examples below ship as runnable, CI-checked code in examples/, using classic public-domain reference datasets bundled in the repo.

Classifying Iris species

Fisher's 150-flower measurements (1936), the standard small classification benchmark. A RandomForestClassifier with 100 trees, fit on 105 flowers, predicting 3 species it never saw.

93.3% accuracy on the held-out split. Petal length/width dominate feature importances (0.39 / 0.48) — consistent with a century of botany.
RandomForestClassifierconfusion_matrixclassification_report
let dataset: Dataset<String> = dataset_from_csv_path("examples/data/iris.csv", true, 4)?; let (train, test) = train_test_split( &dataset, SplitOptions::new(0.3).with_seed(0), )?; let model = RandomForestClassifier::new() .with_n_estimators(100)? .with_seed(0) .fit(&train)?; let predictions = model.predict(test.records())?; let accuracy = accuracy_score(test.targets(), predictions.view())?;

Predicting fuel economy

1974 Motor Trend road-test data for 32 cars. Ten correlated specs on 24 training cars — a natural fit for L2-regularized regression instead of plain least squares.

R² of 0.87, mean absolute error of 1.93 mpg on 8 held-out cars. The largest fitted coefficient is weight (wt) — matching the well-known relationship between mass and fuel economy.

Architecture

A Cargo workspace, not a monolith

The public machlearn crate re-exports a workspace of focused crates, so the dependency graph stays legible as the estimator surface grows.

CrateProvides
machlearn-coreDataset, traits, errors, the faer-backed solver
machlearn-preprocessingScalers, encoders, imputation, pipelines, CSV/Arrow I/O
machlearn-linearOLS, Ridge, Lasso, Elastic Net, logistic regression, LDA
machlearn-treesDecision trees, random forests, gradient boosting, AdaBoost
machlearn-unsupervisedKNN, Naive Bayes, k-means, DBSCAN, Gaussian mixtures, PCA
machlearn-model-selectionCross-validation, grid/randomized search, curves, permutation importance
machlearn-metricsRegression, classification, and probability metrics

Optional Python bindings (python/, via PyO3 + maturin) expose the same estimators to NumPy-backed workflows.
